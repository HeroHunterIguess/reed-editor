# Reed

![image](https://github.com/HeroHunterIguess/reed-editor/blob/main/images/showcase.png)

This is early in development, and not very useful right now but I plan to turn this into a finished simple text editor.
This will not have any advanced editing features or mouse usage, it will remain an extremely simple keyboard-only editor. 

This is made basically just for my personal use. For that reason I also didnt bother to make this super optimized, and thats why I chose pygame. I simply wanted an easy to code, easy to use library to assist in my creation of this project.

Currently certain changes in the config.py file may cause unintended visual bugs. Minimal testing has been done on the configuration options.

A more final release will be posted at a later date, right now there are two pre-releases, but these are extremely early versions that dont really function as a full seamless editor.
